Visitor Analytics Setup

3 steps · ~3 minutes · completely free · invisible to your visitor

Step 1

Create a Google Sheet

Open Google Sheets and create a new blank spreadsheet. Name it something like "Website Visitor Tracker".

Leave it open — you'll need the URL in a moment.

Step 2

Add the Google Apps Script

In your Google Sheet, click Extensions → Apps Script. Delete any existing code and paste this entire script:

// 💌 Visitor Tracker — Google Apps Script // Paste this in Extensions → Apps Script, then click Deploy var SHEET_NAME = "Visitor Log"; function doPost(e) { try { var data = JSON.parse(e.postData.contents); var sheet = SpreadsheetApp.getActiveSpreadsheet() .getSheetByName(SHEET_NAME); // Create the sheet on first run if (!sheet) { sheet = SpreadsheetApp.getActiveSpreadsheet() .insertSheet(SHEET_NAME); // Header row sheet.appendRow([ "Event", "Session ID", "Timestamp (IST)", "Chapter Visited", "Chapter Name", "Furthest Chapter", "Full Journey", "Total Time (sec)", "Chapters Visited Count", "Device", "Browser", "Timezone", "Referrer", "Screen" ]); sheet.getRange(1, 1, 1, 14) .setFontWeight("bold") .setBackground("#3D2B4A") .setFontColor("#FFFFFF"); sheet.setFrozenRows(1); } // Build row based on event type var row = [ data.event || "", data.sessionId || "", data.timestamp ? Utilities.formatDate( new Date(data.timestamp), "Asia/Kolkata", "dd-MM-yyyy HH:mm:ss" ) : "", (data.chapterIndex !== undefined) ? (data.chapterIndex + 1) : "", data.chapterName || "", data.furthestChapterName || data.furthestChapter || "", data.chapterJourney || "", data.totalTimeSeconds || "", data.chaptersVisited || "", data.device || "", data.browser || "", data.timezone || "", data.referrer || "", data.screen || "" ]; sheet.appendRow(row); return ContentService .createTextOutput(JSON.stringify({ status: "ok" })) .setMimeType(ContentService.MimeType.JSON); } catch (err) { return ContentService .createTextOutput(JSON.stringify({ status: "error", msg: err.message })) .setMimeType(ContentService.MimeType.JSON); } } // Allow GET for testing function doGet(e) { return ContentService .createTextOutput(JSON.stringify({ status: "alive", msg: "Tracker is running!" })) .setMimeType(ContentService.MimeType.JSON); }

Then click Save (Ctrl+S / ⌘S).

Step 3

Deploy as a Web App

In Apps Script, click Deploy → New deployment. Configure it like this:

  • Type: Web App
  • Execute as: Me (your Google account)
  • Who has access: Anyone

Click Deploy. Copy the Web App URL it gives you (looks like https://script.google.com/macros/s/ABC.../exec).

⚠️ The URL only appears once right after deploying. Copy it before clicking Done!

Paste your URL here and click Save — it will be written directly into the tracker script:

✅ URL saved! Open js/tracker.js and replace YOUR_APPS_SCRIPT_URL_HERE with the URL you pasted above.
What you'll see

Your Google Sheet Columns

Event Session ID Timestamp (IST) Chapter Visited Chapter Name Furthest Chapter Full Journey Total Time (sec) Device Browser Timezone Referrer

Every time they open a new chapter → one row appears instantly.
When they close the tab → a final session_end row logs their full journey, e.g.:

Chapter 1 — Welcome (12s) → Chapter 2 — Diary (45s) → Chapter 3 — Timeline (120s)
🎉 Once set up, all analytics are completely invisible to your visitor and stored privately in your Google Sheet.
